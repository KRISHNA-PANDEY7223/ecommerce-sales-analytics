E-Commerce Sales Analytics - Project Dependencies

This project requires the following Python packages:

1. DuckDB (version 1.0.0 or higher)
   - Purpose: SQL-based analytical database for fast data analysis
   - Used for: Querying parquet files and executing SQL operations

2. Pandas (version 2.0.0 or higher)
   - Purpose: Data manipulation and analysis library
   - Used for: Dataframe operations and data processing

3. Matplotlib (version 3.7.0 or higher)
   - Purpose: Data visualization library
   - Used for: Creating plots and charts for data visualization

4. Jupyter (version 1.0.0 or higher)
   - Purpose: Interactive computing environment
   - Used for: Running and displaying Jupyter notebooks
